# 🦷 City Smile Dental Clinic – Doctor Portfolio Website

A professional and responsive **portfolio website** for a dental clinic, designed to showcase the clinic's services, doctor profile, testimonials, and online appointment booking features.

🔗 **Live Demo:** [citysmiledentalclinic.vercel.app](https://citysmiledentalclinic.vercel.app/)

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** TailwindCSS
- **Deployment:** Vercel

---

## ✨ Features

- 🧑‍⚕️ Doctor's Profile with Bio & Qualifications
- 🏥 Services Offered (cleaning, implants, braces, etc.)
- 📸 Gallery Section (clinic photos)
- ⭐️ Patient Testimonials
- 📆 Appointment Booking CTA
- 📱 Fully Responsive for Mobile & Desktop
- 🧭 Navbar with Smooth Scrolling
- 🌐 SEO-friendly structure
